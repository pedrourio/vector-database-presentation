O que é?

(embeddings)

Um banco que guarda itens como vetores (embeddings) e responde por semelhança, não por exatidão.

O modelo de embedding transforma significado em números; o banco vetorial só mede a distância

cada número é uma dimensão · 6 de D

gato0.820.14−0.310.670.05−0.48
felino0.790.18−0.270.610.09−0.52
carro−0.440.730.58−0.120.860.31

Os vetores (embeddings) de gato e felino estão próximos; o de carro, longe · valores ilustrativos

  1. 1Parecidos ficam juntos após o cálculo do modelo
  2. 2A consulta também vira ponto
  3. 3k-NN (top-k): os k mais próximos
  4. 4Busca por raio: tudo até a distância r

k = quantidade de resultados · r = distância máxima
Projeção ilustrativa em 2D · cosseno, euclidiana ou produto interno

Como o modelo organiza, indexa e consulta os vetores

GGuilherme Becker apresenta

  1. 1Entra no topo: poucos nós, saltos longos
  2. 2Desce e refina a cada camada
  3. 3Na camada 0, acha os vizinhos

HNSW: grafo hierárquico de proximidade (Malkov e Yashunin, 2020)

itens.sqlpgvector
CREATE TABLE itens (
  id        bigserial PRIMARY KEY,
  embedding vector(768),
  meta      jsonb
);

SELECT id, meta FROM itens
WHERE meta->>'tipo' = 'imagem'
ORDER BY embedding <=> $1
LIMIT 5;
  1. 1O embedding é mais uma coluna
  2. 2Metadados filtram a busca
  3. 3<=> ordena pela distância de cosseno

Exemplo com pgvector (PostgreSQL) · 768 dimensões depende do modelo
