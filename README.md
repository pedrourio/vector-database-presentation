# Bancos de Dados Vetoriais · BAN II

Apresentação da disciplina BAN II sobre bancos de dados vetoriais.

Apresentam: Pedro Henrique Urio dos Santos, Ruan Carlos da Silva, Vitor Rafael Marcelino e Guilherme Becker.

## Como usar

Abra o `index.html` no navegador (é um arquivo único, sem build).

- ← → avança e volta (inclui os passos de cada slide)
- O: parede com todos os slides
- N: notas do apresentador
- P ou `?pdf`: exportar para PDF

Site: https://pedrourio.github.io/vector-database-presentation/
